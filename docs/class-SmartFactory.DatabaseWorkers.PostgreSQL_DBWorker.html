Class: PostgreSQL_DBWorker

class PostgreSQL_DBWorker extends DBWorker { }

Database worker for PostgreSQL using the pgsql extension.

Details

Uses uniquely named native prepared statements so workers sharing one connection do not replace each other's statements. BlobValue binds bytea, while stream_long_data() uses PostgreSQL large objects referenced by OID columns. Large-object reads and writes are performed in an existing or internally owned transaction. SELECT results use forward-only server cursors and fetch one row at a time. Outside an explicit transaction, a read transaction remains open until all shared cursors reach EOF or are freed. Complete these reads before starting an explicit transaction or modifying data on the shared connection.

Method: PostgreSQL_DBWorker::stream_long_data()

public function stream_long_data(string $query_string, $stream, int $type = self::DB_AS_IS): void;

Stores large data from an input stream using one unique bind parameter.

Details

Example:

$stream = fopen(".../large_binary.jpg", "rb");

try {
    $dbw->stream_long_data("UPDATE large_data SET blob_data = ? WHERE id = 1", $stream);
} finally {
    fclose($stream);
}

The new large object and the row update use one transaction. An existing transaction is protected by a savepoint; otherwise this method owns the transaction. Failed uploads are rolled back. Replacing an existing OID does not unlink the old object.

Parameters

Name Pass type Value type Default value Description
$query_string by value string

The INSERT or UPDATE query containing one positional marker or one unique named marker. A named marker may occur in multiple positions.
$stream by value resource

An open readable stream. Reading starts at its current position. The caller retains ownership and must close it. A seekable stream is restored to its initial position.
$type by value int self::DB_AS_IS

DB_AS_IS selects a binary BLOB; DB_STRING selects UTF-8 text. For PostgreSQL this method writes a large object and stores its OID in the target column.

Returns

void

Does not return a value.

Throws

DBWorkerException

If no connection is open, the stream or type is invalid, the query does not contain exactly one unique parameter, or preparing, transferring, updating, or completing the transaction fails.
