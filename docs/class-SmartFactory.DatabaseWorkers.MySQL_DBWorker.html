Class: MySQL_DBWorker

class MySQL_DBWorker extends DBWorker { }

Database worker for MySQL using the mysqli extension.

Details

Implements native query execution, prepared binding and chunked LOB uploads. Results are read sequentially without buffering the complete result set. An unread result must be exhausted or freed before another worker uses the shared connection. The connection uses utf8mb4. SQL literal escaping follows the current SQL mode. mysqli materializes a complete BLOB field when fetching a row; copying that field to a stream does not remove the native row-memory requirement.

Property: MySQL_DBWorker::$statement

protected mixed $statement = null;

Stores this worker's native mysqli prepared statement.

Details

A failed preparation briefly assigns false before native_prepare() resets it to null. The native mixed declaration preserves compatibility with the base property; the PHPDoc type distinguishes mysqli statements from other drivers' handles.

Method: MySQL_DBWorker::native_execute()

protected function native_execute(array $values): void;

Binds validated values and executes the native prepared statement.

Details

Scalar PHP types determine mysqli bind types. LOBs are sent in chunks through send_long_data(); empty LOBs remain distinct from NULL. Result rows are read without buffering the result set, and bound-row references remain stable.
