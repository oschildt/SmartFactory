Class: ConfigSettingsManager

class ConfigSettingsManager extends AbstractSettingsManager { }

Manages configuration in a local JSON file, optionally encrypted and cached in APCu.

Details

Parameter names require no preliminary definitions. Saves merge explicitly assigned parameters into the latest contents under an exclusive lock, preserving concurrent edits to other parameters. Assignments to the same parameter use the last save. Contextual validation supports separate forms; drafts require application-managed storage.
