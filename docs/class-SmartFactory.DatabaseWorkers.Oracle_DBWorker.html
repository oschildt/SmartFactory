Class: Oracle_DBWorker

class Oracle_DBWorker extends DBWorker { }

Database worker for Oracle Database 12c and later using the OCI8 extension.

Details

Uses AL32UTF8 connections, native named binds and explicit temporary BLOB/CLOB descriptors. Automatic identity retrieval discovers the actual identity column and appends RETURNING only for eligible INSERT VALUES statements. Shared transaction state determines whether execution may commit automatically.

A database service is selected when connecting; use_database() changes CURRENT_SCHEMA. LOB fields remain descriptors until read or copied to a stream. Result rows are read sequentially without buffering the complete result set.

Method: Oracle_DBWorker::connect()

public function connect(): void;

Establishes the database connection using the initialized settings.

Details

Uses AL32UTF8 and deterministic NLS date/time and numeric formats. A complete connection_string is used as supplied. Otherwise db_server may contain an Easy Connect descriptor, or a host combined with the db_name service. An optional db_schema changes CURRENT_SCHEMA. A read-only worker starts a managed read-only transaction. An already connected worker keeps its existing connection.

Returns

void

Does not return a value.

Throws

DBWorkerException

If connection settings are incomplete, connection or session initialization fails, the requested call timeout cannot be configured, or a read-only transaction cannot be started.
