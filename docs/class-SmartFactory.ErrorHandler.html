Class: ErrorHandler

class ErrorHandler implements IErrorHandler { }

Logs PHP errors and exception chains without implicitly writing to HTTP responses.

Details

Argument values are omitted by default; explicit argument tracing still masks sensitive parameter names, array keys and SensitiveParameterValue instances. Arbitrary error messages are retained and must not contain application secrets.
