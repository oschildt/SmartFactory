Class: MSSQL_DBWorker

class MSSQL_DBWorker extends DBWorker { }

Database worker for Microsoft SQL Server using the sqlsrv extension.

Details

Uses UTF-8 connections with Multiple Active Result Sets disabled. All queries use forward-only cursors without buffering the complete result set. An unread forward-only result must be exhausted or freed before another request uses the connection. Large result fields are spooled to temporary files; Unicode streams are converted from UTF-16LE without splitting surrogate pairs.

SQL Server has no native read-only transaction mode, so the read_only option is rejected.

Method: MSSQL_DBWorker::create_clone()

public function create_clone(): MSSQL_DBWorker;

Creates a clone of the DBWorker that uses the same open connection.

Details

Exhaust or free an active result before issuing another query through a clone. Closing one worker does not close the shared connection while another worker owns it. A clone shares the same SQL Server session and cannot bypass an unread forward-only result; consume that result to EOF or call free_result() before sending another request.

Returns

MSSQL_DBWorker

Returns a worker sharing the connection and transaction state, with independent statements and results.
