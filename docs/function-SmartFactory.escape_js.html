Function: escape_js()

function escape_js(string $text): string;

Escapes text inside a single- or double-quoted JavaScript string literal.

Details

The enclosing quotes are not added. HTML-sensitive characters are escaped for inline script content. Template literals and HTML attributes require their own context-specific encoding; this function does not provide that encoding.

$text by value string
