Class: DBWorker

abstract
abstract class DBWorker implements IInitable { }

Abstract base class for native database workers.

Details

This wrapper provides a common API for MySQL, PostgreSQL, Microsoft SQL Server and Oracle. Shared implementations validate bind arguments, manage results and streams, and coordinate transaction state. Derived classes implement the native driver operations.

Workers created with create_clone() share connection ownership and transaction state, while their prepared statements and fetched rows remain independent.

Method: DBWorker::fetch_array()

public function fetch_array(array &$rows, array $dimension_keys = [], bool $fields_as_is = false): int;

Fetches all remaining result rows into an array.

Details

By default, rows are appended to a two-dimensional array. Field conversion types are inferred from column metadata, as with explicitly typed RecordsetManager fields. Date/time values become Unix timestamps unless fields_as_is is true. Numeric, string and binary values retain the behavior of the corresponding field accessor.

Example:

$rows = [];
$dbw->fetch_array($rows, ["page_id", "language_key"]);
// $rows[$page_id][$language_key] = ["title" => ..., "content" => ...];

Parameters

Name Pass type Value type Default value Description
$rows by reference array

The target array. Its previous contents are replaced.
$dimension_keys by value string[] []

Field names used as nested array keys, in the supplied order. An empty array appends rows sequentially. Each entry must be a nonempty string field name; numeric column indexes are not accepted. The values read from dimension fields must be integers or strings. Dimension fields are removed from leaf records. Date/time dimensions use Unix timestamps unless fields_as_is is true. Rows with the same complete dimension key overwrite the previous leaf. Invalid entry types are rejected before output is replaced or any row is fetched.
$fields_as_is by value bool false

True reads every field with DB_AS_IS, preserving the driver's decoded values. False selects DB_DATETIME, DB_NUMBER or DB_STRING from column metadata and uses DB_AS_IS for unclassified fields. NULL values remain NULL in both modes.

int

Returns the number of fetched rows, including zero. Errors are reported by exceptions.

Throws

DBWorkerException

If the connection is not open, fetching or LOB decoding fails, a date/time value cannot be parsed, a dimension key is not a nonempty string, or a dimension field is unknown or has a value other than an integer or string.
