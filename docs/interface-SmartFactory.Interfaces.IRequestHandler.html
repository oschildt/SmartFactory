Method: IRequestHandler::init()

public function init(array $parameters): void;

Applies optional dependencies to the request handler.

Parameters

Name Pass type Value type Default value Description
$parameters by value array{ throttling_manager?: (IRequestThrottlingManager | null), user_identificator_getter?: (callable(): (string | int | null) | null) }

An optional throttling manager. Null disables throttling; an omitted entry keeps the current manager. The optional zero-argument identity getter is evaluated on each throttled request; a nonempty string or integer identifies the user, while null or an empty string falls back to the peer IP. Omitted getter settings retain the current getter; null removes it. Implementations may support additional application parameters.

Returns

void

Updates the supplied dependencies without requiring initialization for unthrottled requests.

Throws

\InvalidArgumentException

If throttling_manager is neither null nor an IRequestThrottlingManager implementation, or user_identificator_getter is neither callable nor null.
