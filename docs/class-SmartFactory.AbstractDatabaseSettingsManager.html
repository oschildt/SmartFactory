Method: AbstractDatabaseSettingsManager::withTransaction()

protected function withTransaction(callable $action): array;

Executes one aggregate save inside an owned or caller-managed transaction.

Parameters

Name Pass type Value type Default value Description
$action by value callable(DBWorker): array<string, mixed>

The action which locks, merges and saves the complete settings aggregate.

Returns

array<string, mixed>

Returns the saved snapshot after committing an owned transaction.

Throws

\LogicException

If a required external transaction is absent or an external transaction does not use READ COMMITTED, which is required for fresh reads after acquiring a lock.

\Throwable

If connecting, saving or committing fails. Owned transactions are rolled back; callers retain rollback responsibility for external transactions after any failure.
