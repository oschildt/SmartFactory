20:      * Applies debug settings to new and stored messages without clearing public messages.
21:      *
22:      * Disabling debug mode removes stored programming warnings and debugging messages and
23:      * clears technical information and source locations from errors. Disabling source output
24:      * clears stored source locations. Enabling either option cannot restore removed data.
25:      *
26:      * @param array{debug_mode?: mixed, write_source_file_and_line_by_debug?: mixed} $parameters
27:      * Options are interpreted using PHP nonempty-value semantics; omitted options are disabled.
28:      * Debug mode enables technical diagnostics. Source output additionally enables file names
29:      * and line numbers for errors, programming warnings and debugging messages.
30:      *
31:      * @return void
32:      * Updates the settings and removes stored diagnostics that the new settings disallow.
33:      *
34:      * @author Oleg Schildt
35:      */

44:      * @param array<array-key, mixed> $details

46:      * on the server, and the message should contain some details that may vary from case to case.
