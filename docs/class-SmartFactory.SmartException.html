Class: SmartException

class SmartException extends \Exception { }

Carries a localized message, a stable string error code and optional structured diagnostics.

Details

The string code is available through getErrorCode(); the inherited getCode() remains zero. The original exception or error can be preserved through getPrevious().

Property: SmartException::$error_details

protected array $error_details = [];

Internal variable for storing the error details.

Details

The error details might be useful if the error message translations are provided on the client, not on the server, and the error message should contain some details that may vary from case to case. In that case, the server returns a message identifier and details. The client translates the message and substitutes its parameters using those details. Keys, value types and nested data are preserved.
