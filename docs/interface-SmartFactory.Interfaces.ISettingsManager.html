Interface: ISettingsManager

interface ISettingsManager extends IInitable { }

Provides settings access with explicit validation and persistence operations.

Details

Context selects validation rules for separate forms or wizard steps. Persistence between requests, including wizard drafts, must be provided by the application.

Method: ISettingsManager::saveSettings()

public function saveSettings(): void;

Persists assigned parameters without implicitly validating them.

Returns

void

Clears tracked edits after success. Database managers join an existing READ COMMITTED transaction or create one for the whole save. After an external rollback, reload the snapshot.

Throws

\Throwable

If loading, encoding, locking or writing fails; edits remain available for retry. The caller must roll back an external transaction after any save failure.

Parameter names mapped to their new values.

Allows new names in schema-free managers. With false, only defined parameters are assigned. Fixed-schema managers accept configured fields even if their optional rows are absent and never create unconfigured database columns.
