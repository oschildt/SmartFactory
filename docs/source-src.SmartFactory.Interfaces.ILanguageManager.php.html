103:     /**
104:      * Detects the current language from request parameters, headers and cookies.
105:      *
106:      * Priority:
107:      *
108:      * 1. explicitly set by the request parameter language.
109:      * 2. header 'Content-Language'.
110:      * 3. last language in the cookie.
111:      * 4. browser default language.
112:      * 5. the first one from the supported list.
113:      *
114:      * Some applications may consist of two parts: an administration
115:      * console and a public site. A usual example is a CMS system.
116:      *
117:      * For example, you are using administration console in English
118:      * and editing the public site in German and French.
119:      * When you open the public site for preview in German or French,
120:      * you want it to be open in the corresponding language, but
121:      * the administration console should remain in English.
122:      *
123:      * With the help of $context, you are able to maintain different
124:      * languages for different parts of your application.
125:      * If you do not need the $context, just do not specify it.
126:      *
127:      * Malformed request values are ignored. Accept-Language respects quality weights,
128:      * exclusions, wildcard ranges and header order. Tags are normalized and regional tags
129:      * may fall back to supported parent tags. A nonempty supported-language list is required.
130:      *
131:      * @return void
132:      * Returns without a value.
133:      *
134:      * @throws \LogicException
135:      * If init() has not selected a localization directory.
136:      *
137:      * @throws \RuntimeException
138:      * If a source document cannot be read.
139:      *
140:      * @throws \UnexpectedValueException
141:      * If JSON or a document structure is invalid, or the supported-language list is empty.
142:      *
143:      * @throws \ValueError
144:      * If enabled cookie storage encounters an invalid cookie name or path.
145:      *
146:      * @author Oleg Schildt
147:      */
