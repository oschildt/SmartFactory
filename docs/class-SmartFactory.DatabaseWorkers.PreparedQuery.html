Class: PreparedQuery

final
final class PreparedQuery { }

Compiles public SQL placeholders and validates prepared-query arguments.

Details

Recognizes SQL strings, quoted identifiers, comments and dialect-specific quoting. Only positional ? and named :name markers are accepted. Named occurrences are tracked separately from the unique argument names, allowing one value to serve several positions. No database connection is required for compilation or argument validation.

Method: PreparedQuery::arguments()

public function arguments(array $args): array;

Validates arguments and expands repeated named occurrences into ordered values.

Details

A supplied NULL is recognized as a value. Named array keys may start with one colon. Duplicate normalized names are rejected, and floating-point values must be finite.

Parameters

Name Pass type Value type Default value Description
$args by value array<array-key, mixed>

The variadic argument array received by execute_prepared_query(), optionally containing a single argument array.

Returns

list<(scalar | null | BlobValue | ClobValue)>

Returns values in SQL occurrence order; a repeated name contributes the same value for each occurrence.

Throws

DBWorkerException

If argument names or counts do not match the placeholders, argument styles are mixed, positional keys are not contiguous, names are invalid or duplicated, or values have unsupported types or non-finite floats.

Method: PreparedQuery::compile()

public static function compile(string $sql, string $dialect, bool $backslash_escapes = true): self;

Compiles application bind markers into native SQL without changing quoted SQL content.

Details

Recognizes quoted strings/identifiers, comments, PostgreSQL dollar quotes and JSON operators, and Oracle q/nq quoting. PostgreSQL reuses the same native index for repeated names so all uses participate in native type inference. Parameter values are never inserted into SQL text.

Parameters

Name Pass type Value type Default value Description
$sql by value string

The application SQL containing either ? or :name markers.
$dialect by value string

The SQL dialect: mysql, mssql, postgres or oracle.
$backslash_escapes by value bool true

Whether MySQL backslash escapes are active. Other dialects apply their own quoting rules.

Returns

self

Returns the original SQL, translated SQL and marker occurrence mapping.

Throws

DBWorkerException

If marker styles are mixed, native numbered markers are used, a quoted construct or comment is unterminated, or placeholders occur inside an executable MySQL comment.
