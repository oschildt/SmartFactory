Function: dom_to_array()

function dom_to_array(\DOMElement $node, array &$array): void;

Converts XML child elements to a nested array.

Details

Elements named "item" use their "name" attribute as the array key; other elements use their node name. Text and CDATA become string values when no child elements exist. An array="1" marker takes precedence over formatting whitespace and preserves empty arrays. Comments and processing instructions are ignored. Collections may contain formatting whitespace but not mixed text content.
