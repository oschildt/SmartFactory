Class: UserSettingsManager

class UserSettingsManager extends AbstractDatabaseSettingsManager { }

Manages user settings mapped to database columns and multichoice tables.

Details

New scalar settings require a column and a field/type definition. Values are cached in this object, not in the PHP session. Switching users invalidates the snapshot. Canonical names are table.column; unambiguous short column names remain supported. Saves write only explicitly assigned parameters in one transaction. The first settings table identifies the existing owner and provides the aggregate lock for all user settings.

Method: UserSettingsManager::init()

public function init(array $parameters): void;

Configures scalar and multichoice tables without loading a user's settings.

Parameters

Name Pass type Value type Default value Description
$parameters by value array{ dbworker: DBWorker, settings_tables: array<string, array<string, int>>, multichoice_tables?: array<string, array<string, int>>, identity_fields?: array<string, string>, no_own_transaction?: bool }

Maps tables to ordered field/type definitions. The first field is the user key. Scalar tables need at least one setting field; multichoice tables need exactly two fields. The first scalar table must contain the existing owner row. identity_fields identifies generated keys, for example ["users" => "id"]. Multichoice tables support scalar, numeric and date values; each parameter is addressed by its table name. Set no_own_transaction to require an existing caller-managed transaction.

Example:

$instance->init([
    "dbworker" => app_dbworker(),
    "identity_fields" => ["users" => "id"],
    "settings_tables" => [
        "users" => [
            "id" => DBWorker::DB_NUMBER,
            "language" => DBWorker::DB_STRING,
            "time_zone" => DBWorker::DB_STRING
        ],
        "user_forum_settings" => [
            "user_id" => DBWorker::DB_NUMBER,
            "signature" => DBWorker::DB_STRING,
            "status" => DBWorker::DB_STRING,
            "hide_pictures" => DBWorker::DB_NUMBER,
            "hide_signatures" => DBWorker::DB_NUMBER
        ]
    ],
    "multichoice_tables" => [
        "user_colors" => [
            "user_id" => DBWorker::DB_NUMBER,
            "color" => DBWorker::DB_STRING
        ]
    ]
]);
