Method: LanguageManager::detectLanguage()

public function detectLanguage(): void;

Detects the current language from request parameters, headers and cookies.

Details

Priority:

  1. explicitly set by the request parameter language.
  2. header 'Content-Language'.
  3. last language in the cookie.
  4. browser default language.
  5. the first one from the supported list.

Some applications may consist of two parts: an administration console and a public site. A usual example is a CMS system.

For example, you are using administration console in English and editing the public site in German and French. When you open the public site for preview in German or French, you want it to be open in the corresponding language, but the administration console should remain in English.

With the help of $context, you are able to maintain different languages for different parts of your application. If you do not need the $context, just do not specify it.

Malformed request values are ignored. Accept-Language respects quality weights, exclusions, wildcard ranges and header order. Tags are normalized and regional tags may fall back to supported parent tags. A nonempty supported-language list is required.

Returns

void

Returns without a value.

Throws

\LogicException

If init() has not selected a localization directory.

\RuntimeException

If a source document cannot be read.

\UnexpectedValueException

If JSON or a document structure is invalid, or the supported-language list is empty.

\ValueError

If enabled cookie storage encounters an invalid cookie name or path.

Method: LanguageManager::setContext()

public function setContext(string $context): void;

Sets the current context.

Details

Some applications may consist of two parts: an administration console and a public site. A usual example is a CMS system.

For example, you are using administration console in English and editing the public site in German and French. When you open the public site for preview in German or French, you want it to be open in the corresponding language, but the administration console should remain in English.

With the help of $context, you are able to maintain different languages for different parts of your application. If you do not need the $context, just do not specify it.
