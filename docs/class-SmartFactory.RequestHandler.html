Class: RequestHandler

abstract
abstract class RequestHandler implements IRequestHandler { }

Dispatches API actions to public methods and coordinates parsing, cleanup and responses.

Details

Public application methods are actions. Constructors, destructors, handleRequest(), init() and throttling dependency accessors are excluded. Keep helpers and lifecycle hooks protected or private. Actions receive no arguments. An optional manager limits requests before parsing.

Method: RequestHandler::getRequestThrottlingKey()

protected function getRequestThrottlingKey(): string;

Identifies the caller whose requests share a throttling budget.

Details

Evaluates user_identificator_getter on each request, using its nonempty string or integer result. Null or an empty string falls back to REMOTE_ADDR. Identity sources are prefixed so a user identifier cannot collide with an IP budget. The IP is normalized; forwarded headers are ignored. This hook runs before body parsing and preprocessing and can be overridden.

Returns

string

Returns a user:-prefixed identifier, an ip:-prefixed address, or ip:unknown if no valid IP is available. Integer zero and the string "0" are valid user identifiers and share the same budget.

Throws

\UnexpectedValueException

If the getter returns a value other than string, integer or null.

\Throwable

If the getter throws an exception or error; it is reported by handleRequest() as a system failure.

Method: RequestHandler::handleRequest()

public function handleRequest(): void;

Handles one request using public methods as actions, without a separate action registry.

Details

Resets request state, enforces optional throttling, parses input and invokes an action. Canonical method names exclude lifecycle entry points and dependency accessors from dispatch. Throttled requests receive 429 and Retry-After before body parsing or application hooks. Structured exceptions become client errors; unexpected failures are logged. Cleanup runs after preprocessing starts, even on failure. Response assembly failures produce a minimal response in the handler's format with HTTP status 500. Errors added directly to the message manager select status 400 unless an action, a hook or exception reporting has already selected an error status.

Returns

void

Sends either the prepared response or a neutral system-error fallback.

Throws

\Throwable

If failure reporting or fallback transmission fails; committed output cannot be repaired.

Method: RequestHandler::init()

Applies optional request-handler dependencies without resetting shared throttling history.

Parameters

Name Pass type Value type Default value Description
$parameters by value array{ throttling_manager?: (IRequestThrottlingManager | null), user_identificator_getter?: (callable(): (string | int | null) | null) }

The manager to install, or null to disable throttling. Omission preserves the current manager. The optional zero-argument getter supplies a string, integer or null at request time. Omission preserves the current getter; null removes it. Empty identity results fall back to IP. Additional parameters are reserved for subclasses.
