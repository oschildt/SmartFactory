Function: randomDBShard()

function randomDBShard(string $load_balancing_group): ?\SmartFactory\DatabaseWorkers\DBWorker;

Returns a randomly selected shard worker through the shared shard manager.

Details

Uses deterministic client affinity when enabled in the manager.

Parameters

Name Pass type Value type Default value Description
$load_balancing_group by value string

The name of a nonempty registered load-balancing group.

Returns

?\SmartFactory\DatabaseWorkers\DBWorker

Returns the selected shard's worker, or null if a custom shard manager returns no worker.

Throws

\Exception

If the manager cannot be resolved, the group is unknown, worker initialization fails, or the required client identity is unavailable or invalid.

\Throwable

If creating a custom manager or worker, or calling the configured identifier getter, throws an exception or error, it is propagated unchanged.
