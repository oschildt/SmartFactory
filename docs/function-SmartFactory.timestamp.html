Function: timestamp()

function timestamp(string $time_string, string $format): int|string|null;

Parses a complete date/time string using PHP's DateTime format syntax.

Details

Missing date/time fields are initialized to the Unix epoch's calendar fields in the default timezone, rather than inherited from the current clock. Format reset markers and timezone fields retain their native DateTime semantics.

Parameters

Name Pass type Value type Default value Description
$time_string by value string

The date/time string, or an empty string for an absent value.
$format by value string

The DateTime::createFromFormat() format, for example "Y.m.d H:i:s".

Returns

(int | string | null)

Returns the timestamp on success, null for an empty input, or "error" if parsing fails, emits a warning, or encounters a null byte. Trailing data is rejected.
