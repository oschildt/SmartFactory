Class: RedisRequestThrottlingManager

class RedisRequestThrottlingManager extends AbstractRequestThrottlingManager { }

Stores each caller's JSON history behind an expiring, owner-checked Redis lock.

Details

Requires the optional phpredis extension and a configured Redis connection. Lua guards reads, writes and lock release so an expired owner cannot overwrite another admission. Uses the Redis server clock and expires inactive history after its longest retained window. The client remains owned by the application and is never reconfigured or disconnected.

Throws

Method: RedisRequestThrottlingManager::init()

public function init(array $parameters): void;

Configures the client, namespace, contention settings and inherited rolling-window policy.

Parameters

Name Pass type Value type Default value Description
$parameters by value array{ redis: \Redis, key_prefix?: non-empty-string, limits?: list< array{ 0: positive-int, 1: positive-int } >, lock_ttl_ms?: positive-int, lock_timeout_ms?: non-negative-int, lock_retry_interval_ms?: positive-int }

A phpredis client configured by the application. The default prefix is smartfactory:throttling:. Lock defaults are a 10000 ms lease, 3000 ms contention timeout and 10 ms retry interval. Each lock setting is an integer no greater than 2147483647. A zero timeout permits one attempt. Omitted limits use DEFAULT_LIMITS; an empty list disables all storage access.

Returns

void

Applies validated settings without connecting or changing existing history or client options. Invalid initialization preserves the previous configuration. See RedisRequestThrottlingManager.md.

Throws

\InvalidArgumentException

If redis is not a phpredis client, the prefix is empty, a lock setting is outside its range, or the inherited limit policy is invalid.

\LogicException

If initialization is attempted during an admission operation.

Method: RedisRequestThrottlingManager::saveRecords()

protected function saveRecords(string $key, array $timestamps): void;

Replaces only the active caller's history if the lease is still owned, with atomic expiry.

Parameters

Name Pass type Value type Default value Description
$key by value string

The lowercase SHA-256 caller hash supplied to executeAtomically().
$timestamps by value list<float>

This caller's nonempty, ordered history supplied by the common algorithm.

Returns

void

Stores JSON and a millisecond TTL covering the newest timestamp plus the longest window. Extremely large retention beyond Redis/Lua's safe millisecond range is stored without expiry to avoid discarding active history prematurely. Rejections never call this method or renew TTL.

Throws

\LogicException

If access is outside the active caller's operation or the timestamp list is empty.

\RuntimeException

If the lease was lost or Redis did not confirm persistence.

\JsonException

If the supplied history cannot be encoded as JSON.

\RedisException

If Redis cannot persist history; the atomic boundary wraps the storage failure.
