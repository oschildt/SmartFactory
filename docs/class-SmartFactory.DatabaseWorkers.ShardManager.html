Class: ShardManager

class ShardManager implements IShardManager { }

Class for registering database shards and managing their connections.

Details

Keeps a separate cached DBWorker per registered shard within this instance. Named groups support random selection. Optional affinity uses rendezvous hashing to select the same shard for a stable client identity without persistent storage.

Method: ShardManager::init()

public function init(array $parameters): void;

Initializes deterministic client affinity and the optional user-identifier getter.

Details

Registered shards and cached workers are preserved when initialization is repeated. The getter is called without arguments only when affinity-enabled randomDBShard() is invoked, so authentication may be resolved after object creation. Its nonempty string or integer result replaces the IP/User-Agent identity. Null or an empty string falls back to that fingerprint. No file, PHP session or shared cache is required.

Parameters

Name Pass type Value type Default value Description
$parameters by value array{ pin_shard_to_user_session?: bool, user_identificator_getter?: (callable(): (string | int | null) | null) }

Optional settings. pin_shard_to_user_session defaults to false and the getter defaults to null on every initialization. Any callable representation is accepted for the getter.

Updates affinity settings without invoking the getter or opening database connections.

Method: ShardManager::randomDBShard()

public function randomDBShard(string $load_balancing_group): ?\SmartFactory\DatabaseWorkers\DBWorker;

Returns a random group member, or a deterministic member when client affinity is enabled.

Details

Affinity uses rendezvous hashing of the client identity, group name and shard name. It requires no stored assignments and is independent of registration order. Adding a shard only moves clients for which the new shard wins; removing one only moves its clients. Failed worker initialization propagates without automatic failover.

Method: ShardManager::userSessionHash()

protected function userSessionHash(): string;

Computes the current client's identity hash for deterministic shard selection.

Details

The optional zero-argument getter is evaluated on every affinity-enabled selection. A nonempty string or any integer, including zero, replaces the IP/User-Agent identity. Integer and equivalent string identifiers are normalized to the same identity. A null or empty-string result falls back to REMOTE_ADDR and HTTP_USER_AGENT, as does an omitted getter. Identity sources are separated so an identifier cannot collide with the raw fingerprint merely because its contents match client attributes. Forwarded headers are not interpreted; trusted proxies must normalize REMOTE_ADDR.

Returns

string

Returns the SHA-256 hash of the normalized identifier or the fallback fingerprint.

Throws

\RuntimeException

If fallback identity is needed but the client IP or User-Agent is missing or empty.

\UnexpectedValueException

If the getter returns a value other than string, int or null.

\Throwable

If the getter throws an exception or error, it is propagated unchanged.
