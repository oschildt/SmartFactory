Method: EventManager::addHandler()

public function addHandler(string $event, callable $handler): void;

Adds an event handler unless the same callable is already registered for this event.

Details

Changes take effect immediately, including during an active dispatch. Newly added handlers run after the remaining registered handlers. Closures are identified by object identity; other callables by their function or method and target object/class.

Parameters

Name Pass type Value type Default value Description
$event by value string

Nonempty event code. The string "0" is valid.
$handler by value callable( string, array<array-key, mixed> ): mixed

A function, closure, object method, static method or invokable object accepting the event code and event data. Its return value is ignored. A typical signature is:

function (string $event, array $parameters) : void;

  • $event - the event code.

  • $parameters - the data supplied to fireEvent().

Returns

void

Throws

\InvalidArgumentException

If the event code is an empty string.

Method: EventManager::fireEvent()

public function fireEvent(string $event, array $parameters): int;

Fires an event synchronously, invoking handlers in registration order.

Details

Subscription changes take effect immediately during dispatch. Removed handlers are skipped, newly registered handlers are appended, and suspension stops further invocations while it remains in effect. Removing and registering a handler again creates a new registration at the end, even if it has already run in this dispatch. Recursive dispatches maintain independent invocation counts.

Any exception or error from a handler stops dispatch immediately and is propagated unchanged to the caller. The remaining handlers are not invoked.

Parameters

Name Pass type Value type Default value Description
$event by value string

Nonempty event code. The string "0" is valid.
$parameters by value array<array-key, mixed>

Event data passed to each handler as its second argument.

Returns

int

Returns the number of handlers invoked by this dispatch, or zero if none ran.

Throws

\InvalidArgumentException

If the event code is an empty string.

\Throwable

If a handler throws an exception or error; dispatch stops and the same throwable is propagated.

Method: EventManager::getHandlerKey()

protected function getHandlerKey(callable $handler): string;

Builds an identity key without conflating distinct closure or target objects.

Details

Object references retained by registered closures prevent object ID reuse while their registrations exist. Reflection resolves declared function/method names and class aliases while preserving the called class of static methods and the spelling of dynamic method names passed to call() or callStatic(). An explicit [$closure, '__invoke'] callable has the same identity as that closure.

Parameters

Name Pass type Value type Default value Description
$handler by value callable( string, array<array-key, mixed> ): mixed

The callable whose registration identity is required.

Returns

string

Returns a key identifying a closure object, object method, static method or function.
