Function: dbworker()

function dbworker(array $parameters = [], bool $singleton = true): DatabaseWorkers\DBWorker;

Creates or retrieves a DBWorker object for working with the database.

Details

Supported databases: MySQL, MSSQL, PostgreSQL and Oracle. An already connected singleton is returned without reinitializing its settings. Singletons are shared per driver class in the default factory context, not per connection configuration. Use singleton=false or shards for independent connections. A worker that fails extension validation, initialization or connection is evicted from the singleton cache so a later request can create a clean worker.

$parameters by value array{ db_type: non-empty-string, db_server?: (scalar | \Stringable | null), db_port?: (scalar | \Stringable | null), connection_string?: (scalar | \Stringable | null), db_name?: (scalar | \Stringable | null), db_user?: (scalar | \Stringable | null), db_password?: (scalar | \Stringable | null), db_schema?: (scalar | \Stringable | null), default_isolation_level?: string, isolation_level?: (scalar | \Stringable | null), autoconnect?: mixed, read_only?: mixed, connect_timeout?: (scalar | null), read_timeout?: (scalar | null), query_timeout?: (scalar | null), encrypt?: mixed, trust_server_certificate?: mixed, save_records_explicit_identity?: mixed, auto_returning?: mixed, query_logger?: ( callable( array{ sql: string, duration_ms: (int | float), parameter_types: array<array-key, string>, failed: bool } ): mixed | null ), ...<string, mixed> } []

Connection settings and driver options. Only db_type is always required; the remaining required values depend on the driver and whether a connection is opened. String-valued settings accept scalars, null and Stringable objects because the drivers cast them to strings. Boolean options accept mixed values using PHP truthiness; actual booleans are recommended. auto_returning is disabled only by false. Additional string keys are passed through to the driver for custom options.

  • $parameters["db_type"] - nonempty driver name (MySQL, MSSQL, PostgreSQL or Oracle). A custom name must resolve to a registered DatabaseWorkers\<name>_DBWorker subclass.

  • $parameters["db_server"] - server address

  • $parameters["db_port"] - optional server port, usually an integer or digit string between 1 and 65535; an empty string or null clears an explicitly configured port.

  • $parameters["connection_string"] - optional complete Oracle Easy Connect/TNS descriptor

  • $parameters["db_name"] - database name

  • $parameters["db_user"] - user name

  • $parameters["db_password"] - user password

  • $parameters["default_isolation_level"] - isolation used by start_transaction() when its argument is omitted or NULL; defaults to DBWorker::ISOLATION_READ_COMMITTED.

  • $parameters["autoconnect"] - whether to establish the connection automatically upon creation.

  • $parameters["read_only"] - this parameter sets the connection to the read only mode.

  • $parameters["db_schema"] - optional schema name, interpreted by the selected driver.

  • $parameters["isolation_level"] - optional connection-level isolation, with supported values depending on the driver; distinct from default_isolation_level for transactions.

  • $parameters["connect_timeout"], $parameters["read_timeout"], $parameters["query_timeout"] - timeouts in seconds, where supported by the driver. Scalar values and null are cast to integers; integer values or digit strings are recommended.

  • $parameters["encrypt"], $parameters["trust_server_certificate"] - MSSQL TLS options.

  • $parameters["save_records_explicit_identity"] - enables explicit identity handling in MySQL and MSSQL save_records() operations.

  • $parameters["auto_returning"] - enables Oracle automatic identity retrieval; defaults to true.

  • $parameters["query_logger"] - optional callback receiving the SQL template, duration in milliseconds, parameter type names and failure status. Its return value is ignored.

Example:

use SmartFactory\DatabaseWorkers\DBWorker;

$dbw = dbworker(["db_type" => "MySQL",
                 "db_server" => "localhost",
                 "db_name" => "framework_demo",
                 "db_user" => "root",
                 "db_password" => "root",
                 "default_isolation_level" => DBWorker::ISOLATION_READ_COMMITTED,
                 "autoconnect" => true
                ]);
$singleton by value bool true

If the parameter is true, it ensures that only one instance of this object exists.

Returns

DatabaseWorkers\DBWorker

Returns the initialized database worker.

Throws

\InvalidArgumentException

If the database type is absent, empty or not a string.

ObjectFactoryException

If the driver class is unknown, its factory binding is missing, or resolving it fails validation.

\UnexpectedValueException

If the resolved driver does not extend DatabaseWorkers\DBWorker.

\Exception

If the native database extension is unavailable.

DatabaseWorkers\DBWorkerException

If connection settings or the default isolation level are invalid, or connecting to the database fails.

\Throwable

If autoloading, a custom creation function, or a custom worker method throws an exception or error.
