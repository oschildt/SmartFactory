Class: ObjectFactory

class ObjectFactory { }

Binds implementations to interfaces or parent classes and creates initialized objects.

Details

Bindings can also map a class to itself, allowing a derived implementation to be substituted later without changing business logic. Singleton instances are shared per context and requested contract, rather than per implementation class. Contracts are specified by class/interface names using ::class. Creation functions declare a compatible, non-nullable class or interface as their native return type. Each binding requires a named function or closure that accepts no arguments and constructs, initializes and returns an implementation. The factory never invokes constructors directly and validates each result before returning or caching it.

Method: ObjectFactory::bindFactory()

public static function bindFactory(string $interface_or_class, callable $factory_function, string $context = "default"): void;

Type parameters

  • T of object

Binds a factory function to an interface or class in the specified context.

Details

Contexts have independent bindings and singleton instances, with no fallback to the default context. Specify the requested contract using ::class. Omitting the context registers the default binding. The creation function's declared return type is checked against the contract without invoking the function. Existing bindings can be replaced before a singleton is created. Reset that singleton explicitly before replacing its creation function.

Examples:

ObjectFactory::bindFactory(ILanguageManager::class, function (): LanguageManager {
    $instance = new LanguageManager();

    $instance->detectLanguage();

    return $instance;
});

ObjectFactory::bindFactory(IRecordsetManager::class, function (): RecordsetManager {
    $instance = new RecordsetManager();

    $instance->setDBWorker(singleton(\SmartFactory\DatabaseWorkers\MySQL_DBWorker::class));

    return $instance;
}, "console");

Parameters

Name Pass type Value type Default value Description
$interface_or_class by value class-string<T>

The interface or class name of the requested contract, supplied using ::class.
$factory_function by value callable(): T

A named function or closure called without arguments when an instance is requested. It must declare one non-nullable class or interface return type compatible with the contract and return a fully initialized implementation on each call. Missing, built-in, union and intersection return types are rejected. Method callbacks and invokable objects are not supported.
$context by value string "default"

The binding context; defaults to "default". Any string, including an empty string, is accepted.

Returns

void

Registers the binding without creating an instance.

Throws

ObjectFactoryException

If the contract or declared return type is unknown, the return declaration is missing, unsupported, nullable or incompatible with the contract, the creation function is unsupported or requires arguments, or the contract has a cached singleton or is currently being resolved.

\Throwable

If autoloading the contract or declared return type throws an exception or error, it is propagated.

Method: ObjectFactory::getInstance()

public static function getInstance(string $interface_or_class, bool $singleton, string $context = "default"): object;

Type parameters

  • T of object

Creates and initializes an implementation of the requested contract.

Details

Calls the registered creation function without arguments and verifies that its result implements or extends the requested contract. A singleton is cached only after successful creation and result validation. Failed requests can be retried. Recursive requests for the same contract in the same context are rejected throughout the creation function's execution. Singleton identity is scoped to the context and contract; different contracts bound to the same implementation can have different singleton instances.

Parameters

Name Pass type Value type Default value Description
$interface_or_class by value class-string<T>

The interface or class name of the requested contract, supplied using ::class.
$singleton by value bool

Whether to reuse a cached instance for this context and contract. If false, calls the creation function every time.
$context by value string "default"

The exact binding context, without fallback to the default context.

Returns

T

Returns the fully initialized implementation of the contract.

Throws

ObjectFactoryException

If the contract name is missing or unknown, no binding exists in the context, a circular dependency is detected, or the creation function returns a value that does not implement or extend the requested contract.

\Throwable

If autoloading or the creation function throws an exception or error, it is propagated unchanged and the failed instance is not cached.
