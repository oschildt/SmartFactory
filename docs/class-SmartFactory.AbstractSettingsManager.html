Class: AbstractSettingsManager

abstract
abstract class AbstractSettingsManager implements ISettingsManager { }

Provides lazy loading, parameter access, change tracking and contextual validation.

Details

Values are cached in the object, including empty settings and explicit NULL values. Context selects validation rules; it does not persist wizard drafts between requests. Call loadSettings() explicitly to discard local edits and reload persisted values.
