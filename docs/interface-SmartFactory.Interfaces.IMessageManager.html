public function addError(string $message, array $details = [], string $related_element = "", string $code = "", string $technical_info = "", string $file = "", int|string|null $line = ""): void;

Appends an error without deduplication, preserving structured details and their types.

Parameters

Name Pass type Value type Default value Description
$message by value string

The error message or localization identifier. Only an empty string is ignored; "0" is retained.
$details by value array<array-key, mixed> []

The details might be useful if the message translations are provided on the client, not on the server, and the message should contain some details that may vary from case to case. The server can return a message identifier and details so the client can translate the message and substitute its parameters. Keys, value types and nested data are preserved without conversion.
$related_element by value string ""

The element associated with the error.
$code by value string ""

The error code to be reported.
$technical_info by value string ""

Technical diagnostics, retained only when debug mode is enabled.
$file by value string ""

The source file where the error occurred. An empty string uses the caller's file, if available.
$line by value (int | string | null) ""

The source line as an integer or a numeric string, retained for compatibility with existing callers. Null, an empty string or a value converting to a nonpositive integer uses the caller's line.

Returns

void

Retains the error unless its message is empty. Technical information and source locations are filtered according to the debug settings.

Method: IMessageManager::init()

public function init(array $parameters): void;

Applies debug settings to new and stored messages without clearing public messages.

Details

Disabling debug mode removes stored programming warnings and debugging messages and clears technical information and source locations from errors. Disabling source output clears stored source locations. Enabling either option cannot restore removed data.

Parameters

Name Pass type Value type Default value Description
$parameters by value array{ debug_mode?: mixed, write_source_file_and_line_by_debug?: mixed }

Options are interpreted using PHP nonempty-value semantics; omitted options are disabled. Debug mode enables technical diagnostics. Source output additionally enables file names and line numbers for errors, programming warnings and debugging messages.

Returns

void

Updates the settings and removes stored diagnostics that the new settings disallow.
