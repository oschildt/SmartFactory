Function: aes_256_decrypt()

function aes_256_decrypt(string $edata, string $password_key, bool $allow_legacy = true): string;

Decrypts a versioned AES-256-GCM envelope, optionally accepting legacy AES-CBC data.

Details

New envelopes are authenticated before plaintext is returned. Legacy unprefixed base64(salt || ciphertext) remains readable for migration, but has no integrity protection and cannot reliably detect an incorrect password or tampering. Set allow_legacy to false after old stored data has been re-encrypted.

Parameters

Name Pass type Value type Default value Description
$edata by value string

The ASCII envelope returned by aes_256_encrypt(), or a legacy base64 payload.
$password_key by value string

The password bytes used when the data was encrypted.
$allow_legacy by value bool true

Whether to accept the unauthenticated legacy format. Defaults to true for existing stored data.

Returns

string

Returns the plaintext bytes, including an empty string for a successfully decrypted empty message.

Throws

\UnexpectedValueException

If the envelope has an unknown version, invalid base64, invalid lengths or failed authentication/decryption, or if legacy data is supplied when it is disabled.

\RuntimeException

If the OpenSSL extension is unavailable.
